Guide simple des critères d'accessibilité (RGAA)

RGAA signifie Référentiel Général d'Amélioration de l'Accessibilité. Cette page explique les 13 thèmes d'accessibilité du RGAA dans un langage opérationnel. L'objectif est de comprendre les risques utilisateur et de prioriser les corrections, sans faire croire qu'un pré-audit automatique suffit pour certifier un service.

Auto Partiel Manuel À faire

1. Images

2 auto / 1 partiel / 6 manuels

9 critères

Les images ont-elles une alternative lisible et utile ?

  • 1.1 — img sans alt, SVG/role="img"/canvas sans alternative, input image, area
  • 1.2 — image décorative pourvue d’une alternative ; SVG ni masqué ni nommé (à vérifier)
  • 1.3 — alternative générique, nom de fichier, trop longue

2. Cadres

1 auto / 1 manuel

2 critères

Les cadres (iframe) sont-ils identifiables ?

  • 2.1 — iframe sans title

3. Couleurs

2 auto / 1 manuel

3 critères

Le texte est-il assez contrasté, l’information pas uniquement portée par la couleur ?

  • 3.2 — texte réellement rendu : fond composé (transparences, opacité, éléments superposés), seuils 24 px / 18,5 px gras ; CLI : états survol et focus, thème sombre, thème alternatif du site
  • 3.3 — icône seule d’un bouton ou d’un lien sous 3:1 ; bordures de champs (à vérifier) ; CLI : contraste de l’indicateur de focus (à vérifier)

4. Multimédia

1 auto / 2 partiels / 10 manuels

13 critères

Vidéos et sons : sous-titres, transcription, audiodescription, contrôle de la lecture.

  • 4.3 — vidéo sans piste de sous-titres
  • 4.10 — média en lecture automatique avec le son
  • 4.11 — média sans contrôles natifs

5. Tableaux

2 auto / 2 partiels / 4 manuels

8 critères

Les tableaux de données sont-ils correctement structurés ?

  • 5.1 — tableau complexe sans résumé
  • 5.6 — tableau sans en-tête déclaré
  • 5.7 — th sans scope/id/role, scope invalide, headers cassé
  • 5.8 — tableau de mise en forme avec th, caption, scope…

6. Liens

1 auto / 1 partiel

2 critères

Les liens ont-ils un intitulé compréhensible ?

  • 6.1 — nom accessible sans l’intitulé visible (6.1.5) ; intitulés génériques (à vérifier)
  • 6.2 — lien sans intitulé

7. Scripts

2 auto / 3 manuels

5 critères

Les composants interactifs sont-ils utilisables au clavier et au lecteur d’écran ?

  • 7.1 — rôles invalides ou hors contexte, attributs et valeurs ARIA invalides, états requis, références cassées
  • 7.3 — composants interactifs non focusables, onclick sur élément non interactif

8. Éléments obligatoires

3 auto / 4 partiels / 3 manuels

10 critères

Langue, titre, validité du code : les bases du document.

  • 8.1 — doctype
  • 8.2 — id en double ; CLI --validate-html : validation complète du code généré (html-validate, en local)
  • 8.3 — lang absent sur html
  • 8.4 — code de langue invalide
  • 8.5 — title absent ou vide
  • 8.8 — code de langue invalide sur un élément
  • 8.9 — paragraphes vides servant d’espacement

9. Structuration de l’information

2 auto / 1 partiel / 1 manuel

4 critères

Titres, zones, listes : la page est-elle structurée ?

  • 9.1 — titres vides, role="heading" sans aria-level ; hiérarchie (à vérifier)
  • 9.2 — main absent ou multiple ; header/nav/footer (à vérifier)
  • 9.3 — enfants de ul/ol/dl invalides, li orphelin ; listes simulées (à vérifier)

10. Présentation de l’information

6 auto / 1 partiel / 7 manuels

14 critères

Focus visible, zoom, affichage mobile, contenus masqués.

  • 10.1 — balises et attributs de présentation
  • 10.4 — texte tronqué à 200 %
  • 10.6 — lien dans le texte non souligné et sous 3:1 avec le texte
  • 10.7 — CLI : comparaison d’images focus/sans focus sur le parcours clavier ; CSS supprimant le contour (à vérifier)
  • 10.8 — élément focusable dans une zone aria-hidden
  • 10.11 — défilement horizontal à 320 px
  • 10.12 — texte tronqué avec l’espacement du test 10.12

11. Formulaires

3 auto / 4 partiels / 6 manuels

13 critères

Étiquettes, regroupements, erreurs et aide à la saisie.

  • 11.1 — champ sans étiquette, placeholder seul, label for orphelin ; étiquette implicite (à vérifier)
  • 11.2 — nom accessible sans l’étiquette visible (11.2.5)
  • 11.5 — boutons radio / cases à cocher de même nom non regroupés
  • 11.6 — regroupement sans légende
  • 11.9 — bouton sans intitulé, nom sans l’intitulé visible (11.9.2)
  • 11.10 — obligation non signalée, erreur non associée
  • 11.13 — valeur autocomplete invalide ; autocomplete manquant (à vérifier)

12. Navigation

2 auto / 1 partiel / 8 manuels

11 critères

Liens d’évitement, ordre de tabulation, pièges clavier.

  • 12.7 — lien d’évitement absent, cible absente ; CLI : visible au focus et fonctionnel
  • 12.8 — tabindex positif
  • 12.9 — focus bloqué sur un élément pendant le parcours clavier

13. Consultation

1 auto / 3 partiels / 8 manuels

12 critères

Rafraîchissements, documents, animations et mouvements.

  • 13.1 — meta refresh et redirection différée
  • 13.3 — documents bureautiques sans format annoncé
  • 13.7 — animations en boucle plus rapides que 3 cycles par seconde
  • 13.8 — marquee/blink (non conforme) ; animations infinies, vidéo en boucle (à vérifier)

Comment utiliser ce guide ? Commencez par les thèmes avec le plus de critères manuels (multimédia, présentation, consultation). Ce sont eux qui demandent le plus souvent une revue humaine.

État de couverture actuel (RGAA 4.1.2) : 28 critères automatisés (26.4 %), 20 partiels (18.9 %), 58 manuels (54.7 %).
